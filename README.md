# Hiya Verma: Resume Site
 
My personal resume website, built with React and TypeScript.
 
🔗 **Live site:** (https://hv-resume-react-qrij.vercel.app/)

 
## Pages
 
- **Home:** an introduction and short bio
- **Education:** Boston University, B.S. Data Science
- **Experience:** internships and teaching
- **Projects:** hackathon projects plus a small interactive calculator
- **Certifications:** AWS Cloud Practitioner, Google Data Analytics, and other honors
## Tech stack
 
- React 19 + TypeScript
- Vite
- React Router (client-side routing)
- styled-components (responsive layout)
- ESLint
## Run locally
 
```bash
npm install
npm run dev      # start the dev server
npm run build    # create a production build
```
